# A slight variation to your default Omarchy waybar. 

### How to use - 

Backup up default config files in the /home/usr/.cong/waybar/ folder
Replace the config.jsonc and style.css files
Go to your preffered theme folder (/home/usr/.config/omarchy/themes/) and add the example overrides.css and waybar.css files

The overrides.css and waybar.css are there for flexibility of making elements suitable for your preffered theme. 
Feel free to add overrides.css and waybar.css to your light and dark themes and change parameters for elements to your preference
The example overrides.css and waybar.css provided are suitable for dark themes like midnight
